# Решения по мобильному приложению

## 2026-11-17 — редизайн и кабинет

- Сохранить текущую авторизацию по email OTP, bearer-клиент и экран видеоурока. Новая навигация не меняет API-вызовы существующих функций.
- Развить имеющуюся льняную и терракотовую палитру. Использовать локальные Inter и Cormorant Garamond с кириллицей, системную светлую/тёмную тему и ручное переключение.
- Публичный мобильный каталог пока демонстрационный: в `account` API нет публичного списка и актуальных цен. Оформление открывает сайт.
- «Записи и материалы» показывает купленные онлайн-курсы из `account.myCourses`. Очные «Предстоящие», «Прошедшие», «Отменённые» остаются пустыми до появления контракта записей. Не показывать вымышленные билеты, даты и QR-коды реальным пользователям.
- Кэш онлайн-курсов хранится по идентификатору пользователя в Capacitor Preferences и используется при отсутствии сети. Офлайн-билеты и локальные напоминания требуют серверных данных о записи и времени занятия.
- Демонстрационная запись доступна только в dev-режиме с `?demo-bookings=1`. Профиль объясняет, почему настройки напоминаний пока недоступны. Новый нативный плагин не добавляли: без дат занятий он не выполнял бы полезной работы и потребовал бы выпуска новой оболочки.
- `docs/BRIEF.md` отсутствует; визуальные решения основаны на действующей палитре мобильного приложения и фотографиях из репозитория.
