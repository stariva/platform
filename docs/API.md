# Мобильный API видеокурсов Stariva

Мобильное приложение использует типизированный oRPC-контракт
`packages/web-api/src/contract/account.ts`. Вход по email OTP создаёт
bearer-сессию того же аккаунта, что на сайте.

## Каталог и покупка

`account.catalogCourses` публично возвращает опубликованные видеокурсы из
основной базы: обложку, категорию, уровень, число уроков, актуальную цену и
признак предзаказа. Карточка ведёт сразу на `/workshops/{slug}` на сайте,
где работает существующая оплата. После предоставления доступа купленный
курс появляется в `account.myCourses`.

Покупка внутри приложения пока не реализована. Для неё нужен согласованный
мобильный checkout и обработка возврата из платёжного сервиса. Сейчас ссылка
на конкретный курс сохраняет рабочий путь оплаты без дублирования логики.

## Просмотр

`account.myCourses` возвращает купленные курсы с `firstLessonId`,
прогрессом и последним незавершённым уроком. Архивный курс остаётся
доступным покупателю. `lessonDetails` отдаёт список уроков, главы,
чек-лист и вложения. `lessonVideo` выдаёт временную ссылку для HLS/MP4.
`saveLessonProgress` и `saveLessonChecklist` сохраняют работу зрителя.
`materialUrl` выдаёт ссылку на PDF курса или схему урока: в ссылке короткий
пропуск, поэтому приложение открывает её в системном браузере без cookie сайта.
`workshopReview` отдаёт уже оставленный отзыв, а `saveWorkshopReview` его
заменяет — прежние фото форма передаёт в `keepPhotos`.

Список купленных курсов кэшируется на устройстве для показа без сети;
воспроизведение видео и загрузка вложений требуют подключения.
