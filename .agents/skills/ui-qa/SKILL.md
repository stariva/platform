# Визуальная проверка UI

1. Убедись, что dev-сервер запущен (`npm run dev`, порт обычно 5173).
2. Через MCP `playwright` открой нужный маршрут и сделай скриншоты:
   - 375×812 (iPhone-класс) и 412×915 (Android-класс)
   - светлая и тёмная тема (`prefers-color-scheme` или переключатель в приложении)
3. Внимательно рассмотри каждый скриншот. Ищи:
   - обрезанный/налезающий текст, переносы заголовков, кириллические шрифты-фолбэки
   - нарушенные отступы и выравнивания, выход за safe-area
   - слабый контраст, мелкий текст, зоны нажатия < 44 px
   - «пустые» состояния и скелетоны, ошибки загрузки изображений
4. Проверь интерактив: открыть/закрыть bottom sheet, табы, форма записи, валидация.
5. Проверь консоль браузера — ошибок и предупреждений быть не должно.
6. Исправь найденное и повтори шаги 2–5. Остановись, когда замечаний нет.
7. В ответе кратко перечисли, что проверено и что исправлено.
